個人專案 (Projects)

AceNexus — Spring Cloud 微服務基礎架構

自主設計並實作一套完整的微服務基礎設施，包含三個核心服務：

  • GATEWAYSERVICE：自定義 JWT 全域過濾器，驗證後將 User ID 注入下游 Header，消除各服務重複驗證邏輯；整合請求 Log 追蹤 (Request ID, IP, Duration)。
  • CONFIGSERVICE：以 Git 為配置後端，整合 JCE 加密敏感參數；搭配 RabbitMQ + Spring Cloud Bus，實現配置熱更新無需重啟服務。
  • EUREKASERVICE：整合 HTTP Basic Auth 防止未授權節點註冊，心跳超時 45 秒自動剔除失效節點。

CI/CD 透過 GitHub Actions 建置 Docker 映像並推送至 GHCR，再由 ArgoCD 監控 deploy repo 自動同步至 K8s 叢集。

NEXUSBOT — LINE Bot 智慧助理

基於 Java 17 + Spring Boot 建構的 LINE Bot 服務，核心設計重點：

  • 責任鏈模式 (Chain of Responsibility)：依優先順序串接多個事件處理器（管理員指令 → AI 閒聊 → 預設回覆），新增功能不影響現有邏輯，符合開閉原則。
  • AI 整合：串接 Groq API (Llama 3.1) 提供智慧對話；支援單次、每日、每週排程提醒並處理跨時區轉換。
  • 可觀測性：整合 MDC TraceID 追蹤請求鏈路，搭配 Grafana 監控。
  • 資料庫版本控制：使用 Flyway 管理 MySQL Schema，確保各環境 (Local/Dev/Prod) 結構一致。
