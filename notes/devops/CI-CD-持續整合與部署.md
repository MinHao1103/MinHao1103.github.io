# CI/CD 持續整合與部署

CI/CD 是現代軟體開發的核心實踐，透過自動化流程縮短交付週期、降低人工錯誤風險。

---

## 1. 核心概念

### CI — 持續整合（Continuous Integration）

開發者將程式碼合併到共用儲存庫後，系統自動執行建置與測試，盡早發現問題。

### CD — 持續交付（Continuous Delivery）

確保通過測試的程式碼隨時都處於可部署到正式環境的狀態。

### CD — 持續部署（Continuous Deployment）

更進一步：通過所有測試的每個變更都**自動部署**到正式環境，無需人工介入。

---

## 2. 目的

| 目的 | 說明 |
|------|------|
| **節省時間** | 自動化取代手動建置、測試、部署 |
| **降低風險** | 每次合併都觸發測試，及早發現回歸問題 |
| **穩定交付** | 避免手動部署造成的人為錯誤 |

---

## 3. 常見工具

- **Jenkins** — 老牌開源 CI/CD 伺服器，彈性高
- **GitLab CI/CD** — 與 GitLab 深度整合
- **GitHub Actions** — GitHub 原生，設定簡單
- **Travis CI** — 雲端 CI 服務
- **CircleCI** — 雲端 CI/CD，速度快
- **Azure DevOps** — Microsoft 生態系整合
