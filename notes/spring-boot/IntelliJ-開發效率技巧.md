# IntelliJ IDEA 開發效率技巧

這篇筆記記錄了提升 IntelliJ IDEA 開發速度的常用快捷鍵。
原因是熟練使用 IDE 快捷鍵能省下大量滑鼠操作時間，讓開發節奏更順暢。

---

## 1. 常用快捷鍵
- **程式碼生成**：`Alt + Insert` (產生 Getter/Setter、建構子)。
- **快速修復與提示**：`Alt + Enter` (自動匯入套件、修復語法錯誤)。
- **格式化排版**：`Ctrl + Alt + L` (保持程式碼風格一致)。
- **全域搜尋**：`Shift + Shift` (Search Everywhere，找檔案或類別最快的方式)。

---

## 2. 實用外掛建議
預計在微服務開發時，建議安裝以下外掛：
- **Lombok**：自動產生樣板程式碼。
- **SonarLint**：即時檢查程式碼品質與潛在 Bug。
