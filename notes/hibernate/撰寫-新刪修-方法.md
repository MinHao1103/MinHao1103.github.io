# Hibernate 基礎 CRUD 操作

這篇筆記記錄了直接透過 Hibernate Session 進行資料新增、修改與刪除的方法。
原因是理解這些原生 API 的行為，能幫助我們釐清資料在 Persistence Context 中的狀態轉換。

## 1. 新增 (Insert)
- 使用 `session.save(entity)`。
- 物件從 Transient (瞬態) 轉變為 Persistent (永續態)，並被納入 Session 管理。

## 2. 修改 (Update)
- 使用 `session.update(entity)`。
- 實務上更常見的做法是：先 `get()` 出實體物件，直接呼叫 Setter 修改屬性。只要 Transaction 結束 (Commit)，Hibernate 會自動發出 `UPDATE` 語句（這稱為 **Dirty Checking** 機制）。

## 3. 刪除 (Delete)
- 使用 `session.delete(entity)`。
- 必須先確保物件有被賦予正確的主鍵 (OID)。

## 4. 儲存或更新 (SaveOrUpdate)
- 使用 `session.saveOrUpdate(entity)`。
- 如果物件沒有 OID，視為新增；如果有，則視為修改。

> 💡 **現況總結**：目前在使用 Spring Data JPA 時，上述操作已經全部簡化為呼叫 `repository.save()` 或 `repository.delete()`。
