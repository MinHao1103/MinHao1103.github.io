( 九 ) 使用 Hibernate 撰寫 新 / 刪 / 修 方法
===
# ( 1 ) 新增 方法
:::warning
* 說明
    * 在底層執行 SQL 的 insert 敘述
    * 使實體物件的狀態從
        * 臨時狀態 ( Transient ) 變成 永續狀態 ( Persistent )
    * 若想在新增時，跳過某欄位
        * 可使用 @Column(insertable = false)
    * 若想取得新增時，產生的識別值
        * Session 型態有定義對應的用法
* 相關方法
    * Serializable save ( Object object )
        * 將實體物件新增至對應的資料表中
        * object　欲新增至資料表中的實體物件
        * 物件應為臨時狀態 Transient
        * 回傳產生的識別值
    * void persist ( Object object )
        * 將實體物件新增至對應的資料表中
        * object　欲新增至資料表中的實體物件
        * 物件應為臨時狀態 Transient
    * save 與 persist 差別在於有無回傳產生的識別值
:::

## ( 1-1 ) save()
```java=
@Override
public int insert(Member member) {

	// 取得連線
	Session session = HibernateUtil.getSessionFactory().getCurrentSession();

	try {
		// beginTransaction 開始交易
		Transaction transaction = session.beginTransaction();
		// save 相當於 JDBC Insert，會回傳識別值
		Integer id = (Integer) session.save(member);
		// commit 交易結束
		transaction.commit();
		return id;
	} catch (Exception e) {
		// 當有 Exception，則 rollback
		session.getTransaction().rollback();
		e.printStackTrace();
	}

	return 0;
}
```

## ( 1-2 ) persist()
```java=
@Override
public Boolean insert(Member member) {

	// 取得連線
	Session session = HibernateUtil.getSessionFactory().getCurrentSession();

	try {
		// beginTransaction 開始交易
		Transaction transaction = session.beginTransaction();
		// save 相當於 JDBC Insert，不會回傳識別值
		session.persist(member);
		// commit 交易結束
		transaction.commit();
		return true;
	} catch (Exception e) {
		// 當有 Exception，則 rollback
		session.getTransaction().rollback();
		e.printStackTrace();
	}

	return false;
}
```

# ( 2 ) 刪除方法
:::warning
* 說明
    * 在底層執行 SQL 的 delete 敘述
    * 使實體物件的狀態從
        * 永續狀態 ( Persistent ) 變成 移除狀態 ( Removed )
    * Session 型態提供的刪除相關方法，只適用於藉由 OID 刪除資料
        * 使用上可傳入臨時狀態 ( Transient ) 的實體物件，但 OID 必須有值
        * Hibernate 會在底層將其轉成永續狀態 ( Persistent )
        * 刪除後變成移除狀態 ( Removed )
* 相關方法
    * void delete ( Object object )
    * void remove ( Object object )
        * 說明
            * 將實體物件從對應的資料表中刪除
        * 參數
            * object：欲從資料表中刪除的實體物件
            * 該物件可以是臨時狀態 ( Transient ) 或 永續狀態 ( Persistent )
    * 以上兩種方法無任何差別
:::

## ( 2-1 ) delete()
```java=
public boolean deleteByIdUseDelete(Integer id) {
    SessionFactory sessionFactory = HibernateUtil.getSessionFactory();
    Session session = sessionFactory.getCurrentSession();
    try {
        Transaction transaction = session.beginTransaction();
        Member member = session.load(Member.class, id);
        session.delete(member);
        transaction.commit();
    return true;
    } catch (HibernateException e) {
        session.getTransaction().rollback();
        e.printStackTrace();
    }
    return false;
}
```

# ( 3 ) 修改方法
:::warning
* 說明
    * 在底層執行 SQL 的 update 敘述
        * 1.先透過 session.get()、session.load() 取得實體物件
        * 2.透過 Setter 修改屬性值
        * 3.transaction.commit()
    * Session 型態提供的修改相關方法，只適用於藉由 OID 修改資料
    * 若想在修改時跳過某欄位，可使用 @Column(updatable = false)
        * 但設定後會造成使用缺乏彈性
    * 另外 saveOrUpdate()、merge()，可視情況執行 SQL 的 insert/update 敘述
* 相關方法
    * void update(Object object)
        * 說明
            * 修改實體物件對應資料表中的資料
        * 參數
            * object：欲修改至資料表中的實體物件
            * 該物件可以是臨時狀態 ( Transient ) 或 分離狀態 ( Detached )
* Session 型態提供的相關方法
    * void saveOrUpdate(Object object)
        * 說明
            * 若 OID 找的到對應的欄位值，則執行修改 SQL 的 update 敘述 ( 同 update() )
            * 找不到對應的欄位值，則會拋出 OptimisticLockException
            * 無值，則執行新增 SQL 的 insert 敘述
        * 參數
            * object: 欲新增 / 修改至資料表中的實體物件
            * 該物件可以是臨時狀態 ( Transient ) 或 分離狀態 ( Detached )
    * Object merge(Object object)
        * 說明
            * 若 OID 找的到對應的欄位值，則執行修改 SQL 的 update 敘述 ( 同 update () )
            * 找不到對應的欄位值或無值，則執行新增 SQL 的 insert 敘述
        * 參數
            * object: 欲新增/修改至資料表中的實體物件
                * 該物件可以是臨時狀態 ( Transient ) 或 分離狀態 ( Detached )
        * 回傳
            * 異動後的實體物件，永續狀態(Persistent)
:::

## 補充 [Apache Commons Lang](https://mvnrepository.com/artifact/org.apache.commons/commons-lang3)
## ( 3-1 ) Setter
```java=
import static core.util.HibernateUtil.*;

	public boolean updateByIdUseSetter(MemberPojo newMember) {
		
		Session session = getSessionFactory().openSession();
		try {
			Transaction transaction = session.beginTransaction();
			// 先透過 session.get()、session.load() 取得實體物件
			MemberPojo oldMember = session.load(MemberPojo.class, newMember.getMemberId());
			
			String name = newMember.getName();
			// 如果接收到的 name 不為空的話，就將值 set 到 oldMember ( 資料庫原本的值 )
			if(StringUtils.isNotEmpty(name)) {
				oldMember.setName(name);
			}
			transaction.commit();
			return true;
		} catch (HibernateException e) {
			session.getTransaction().rollback();
			e.printStackTrace();
			return false;
		}
	}
```
